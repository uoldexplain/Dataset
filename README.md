# UOLD, Version 2

## Important notice about this version

Version 2 of this dataset does not include the tweet text** (`tweetText`).
Version 1 contained the original tweet text. 
It has been withdrawn because the X (formerly Twitter) Developer Policy does not allow public redistribution of tweet content. We have updated the release so that it complies with the policy.


The dataset contains [24,063] tweets. No usernames, user IDs, or other user metadata are released.

## How to obtain the tweet text

Researchers have two options:

1. **Rehydrate the tweets yourself.** Use the Twitter IDs with the X API, subject to X's terms. Tweets that have been deleted or made private since collection will no longer be retrievable.
2. **Request the complete dataset from the authors.** The version with tweet text is available for non-commercial research purposes under a data-use agreement. To request it, please email the corresponding author at **[email address]** with the subject line "[Dataset name] data request", and include:
   - Your name, institution, and institutional email address
   - A short description of your intended research use
   - Confirmation that you have read and agree to the data-use agreement below

Requests are reviewed manually, and the text is sent privately to approved requesters. We aim to reply within [X] working days.

## Data-use agreement (summary)

By requesting the tweet text, you agree to:

- use the data for non-commercial research only [and in line with X's terms regarding AI/ML use, confirm before publishing];
- accept and comply with X's Terms of Service, Privacy Policy, Developer Agreement, and Developer Policy;
- not redistribute, publish, or post the tweet text, in whole or in part, in any public repository;
- not attempt to identify, contact, or profile any individual author;
- delete any tweets that have been removed from X or that we notify you should be removed, and apply updates to the dataset when we send them.
